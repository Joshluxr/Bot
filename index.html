Usage Guide

Starting a New Range

  1. Use range_splitter.py to convert and split the decimal range: 
    python3 range_splitter.py START_DECIMAL END_DECIMAL
  2. Copy the hex arrays into a new launch script (use launch_template.sh)
  3. Deploy to server: scp -P PORT launch_script.sh root@SERVER:/root/searchk4_hybrid/SearchK4_optimized/
  4. Run: bash launch_script.sh
  5. Start hourly logger: nohup bash hourly_progress.sh &

SearchK4 Binary Flags

Use SINGLE DASH flags only. Double-dash (--gpu) will fail.
FlagDescription
-patternsPath to hash160 patterns file
-directDirect key iteration mode
-startxStart hex range (0x-prefixed)
-endxEnd hex range (0x-prefixed)
-gpuGPU index (0-7)
-oOutput file for matches
-stateState file for checkpointing

Resuming After Crash

for i in {0..7}; do
  nohup ./searchk4_fast \
    -patterns combined_patterns.txt \
    -direct \
    -state gpu${i}_r7.state \
    -endx ${END_HEX[$i]} \
    -gpu $i \
    -o gpu${i}_r7_found.txt \
    > gpu${i}_r7.log 2>&1 &
done

Checking for Matches

# Any non-empty found file = MATCH
for i in {0..7}; do
  [ -s gpu${i}_r7_found.txt ] && echo "MATCH on GPU $i!" && cat gpu${i}_r7_found.txt || echo "GPU $i: no match"
done

Troubleshooting

Permission denied (publickey)

Server lost SSH key. Re-add via vast.ai dashboard:

ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAICYREBDG0rvl18yJCB3IzLzyaQdQB6UvswpXWsyJuCE1 devin@cognition.ai

Processes died (0% GPU utilization)

  1. Verify state files: ls -la gpu*_r7.state (should be ~40MB each)
  2. Run resume_range7.sh
  3. Verify: nvidia-smi should show 100% within 15 seconds

Connection refused

Server down or port changed. Check vast.ai dashboard for current SSH connection details. Server address and port may change after restarts.

"Unknown or incomplete option"

Used double-dash flags. Change --gpu to -gpu, --patterns to -patterns, etc.
